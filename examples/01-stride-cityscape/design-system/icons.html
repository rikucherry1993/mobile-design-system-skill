Icons

Token-driven inline SVG sprite: stroke:currentColor; stroke-width:var(--icon-stroke), so the set reskins with the theme (thin technical outline, 1.5 stroke, butt caps / miter joins — set by --icon-stroke / --icon-cap / --icon-join). Use with <svg class="ico"><use href="#i-run"/></svg>. Never emoji.

Terrain layer

Stride has no drawn illustrations — imagery is real, faded outdoor photography under a flat scrim, with yellow contours and the hand-drawn route on top (see styles.css TERRAIN LAYER and the concept).
